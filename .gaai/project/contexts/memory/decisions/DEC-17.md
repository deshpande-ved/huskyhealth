# DEC-17 — Voice in only by opt-in; clone only a consenting coach

## Context
A voiceprint is a biometric identifier.

## Decision
The mic is off unless voice check-ins are turned on; only a number survives. Cloning is only of a consenting coach, labeled as AI and deletable.

## Impact
Enforced by PRIV-4/PRIV-5.
