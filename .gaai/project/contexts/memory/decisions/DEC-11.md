# DEC-11 — Voice out by default; Gradium plus phone voice

## Context
Speaking needs no personal data; listening does.

## Decision
Voice output (Gradium TTS, or the phone's own voice) is on by default; voice input is opt-in only.

## Impact
See DEC-17 for voice-in consent rules.
