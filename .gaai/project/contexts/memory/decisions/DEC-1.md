# DEC-1 — PWA for the hackathon, native app after

## Context
No native app can ship in the HACK1984 weekend.

## Decision
Ship an installable PWA; a native iOS app moves to after HACK1984.

## Impact
A link works for anyone, installs to the Home Screen and runs offline. All client work targets `web/`.
