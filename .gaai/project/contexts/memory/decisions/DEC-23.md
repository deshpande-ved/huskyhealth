# DEC-23 — Tracks are guidelines: list three, add Surge if F19 ships, skip Signal-to-Dose

## Context
DEC-14 picked three HACK1984 tracks and said to skip Surge and Signal-to-Dose. The organizers then said every project is judged for all tracks; the tracks a team picks are only guidelines. Skipping a track no longer removes the project from its judging, so the open question is which tracks to name and build toward.

## Decision
Name Privacy-First, Most Startup-able and Best Use of Gradium as the project's tracks. Also list Surge if F19 (the Tavily/Exa evidence agent) ships. Do not pursue Signal-to-Dose: it asks for drug-launch signals on a self-hosted 3B model, and HuskyHealth has no training set for that.

## Impact
- Supersedes DEC-14.
- F19 stays an optional, cuttable extra (DEC-18), but shipping it now also earns a Surge listing.
- No story is written for Signal-to-Dose.
