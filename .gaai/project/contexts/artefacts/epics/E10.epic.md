# Epic: Extras

## Purpose

Four optional extras from the feature menu (F16–F19) that add value on top of the readiness brief: plan a taper before a match, ask questions about your own training, measure how de-identified the brief really is, and show recent studies behind each method. Each one is independently cuttable (DEC-18): Ved decides which ship.

Source: runbook Part E, epic E10; memory `project/ai-voice.md` [8.2], `project/evidence.md` [9.2], `project/ai-brief-relay.md` [8.3], `project/engine.md` [7].

---

## Scope

One feature group per extra. A group is the one story, or the set of sub-stories, that ships the feature; sub-stories in a group are cut together.

- **F16 Match taper planner** (E10S01 + E10S08, cut together): "match in N days" (a count, never a date). The engine sets daily load ranges by standard tapering and the page draws them as an ASCII calendar (E10S01, no network request). Claude only names a squash session for each day from a fixed list (E10S08); the relay checks the reply and the page falls back to the ranges alone if it fails.
- **F17 Ask HuskyHealth** (E10S02 + E10S03, cut together): a question box. Presidio strips names and places first; the page sends up to 12 rounded weekly summaries; Claude may call three narrow lookups the relay evaluates over that request only; the page lists every lookup. Nothing stored. AI explains, never makes the call.
- **F18 ARX risk analysis** (E10S04 + E10S05, cut together): a synthetic `BriefIn` cohort, measured re-identification risk before and after rounding, chosen widths copied into `bucketize()`, a before/after slide text.
- **F19 Evidence agent** (E10S06 + E10S07, cut together): on a References card, a "Show recent studies" tap makes the relay search Tavily with fixed, generic queries per method (no user data, ever), caches per method, and Claude writes one-line summaries of three cited sources. Nothing loads when the card opens; a one-line notice names Anthropic Claude and Tavily beside the button. Search egress is a mitmweb reverse listener on internal port 8083, compose network only. Shipping F19 adds a Surge track listing (DEC-23).

Every group keeps PRIV, CLAIM and FE rules: training language only, "de-identified" wording, rules decide and AI explains, consent and preview before anything user-derived leaves the phone, Presidio on every outbound text path, no logging of content.

---

## Out of Scope

- Injury prediction or "injury risk" wording; medical claims.
- Dates in any request (taper input is a count; weekly summaries use a relative week index).
- Any user number, date, sport or text in a search query (F19).
- Storing questions, answers or plans anywhere (relay or phone).
- Shareable AI recaps; cloning a user's voice; always-on listening.
- Signal-to-Dose (DEC-23).
- Changing the engine's readiness call or the `BriefIn` schema.
