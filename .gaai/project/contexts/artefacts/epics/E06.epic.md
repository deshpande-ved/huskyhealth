# Epic: Sync API (convenience mode, F13: the headline)

## Purpose

An athlete who opts in no longer has to re-export Apple Health to see new workouts. A Shortcut drops new workouts on the relay, encrypted to a key only the phone holds, and the app collects them the next time it opens. The default airplane-mode story stays intact: the mode is OFF until the user turns it on, and while it is off there are no keys and no network calls.

---

## Scope

Exactly the five stories in the runbook's E06 spec (source: plan 5.4, memory `project/sync-api.md`):

- A drop box on the relay that holds only ciphertext, in RAM, for at most 24 hours (`POST /v1/box`, `POST /v1/drop/<box>`, `GET /v1/drop/<box>`, `DELETE /v1/box/<box>`, using `seal()` from 5.4).
- Pairing in the PWA: a Settings toggle OFF by default, a consent screen worded as in 5.4, a non-extractable RSA-OAEP key pair kept in IndexedDB, and a pairing code shown once.
- Collect on open: fetch the drop, decrypt it on the phone, merge the new days into features; the server copy is gone after the read.
- A public Shortcut build sheet (Claude Code can't build Shortcuts) with the payload schema, the triggers and a `state.json` throttle.
- A turn-off flow that deletes the keys and the box, plus a demo script.

Constraints carried by every story: DEC-16, DEC-21, PRIV-4 (OFF by default), PRIV-6 (nothing logged), PRIV-7 (RAM only), PRIV-9 (CSP), SAFE-2 (public docs carry no homelab details).

---

## Out of Scope

- Any background sync that runs without a Shortcut trigger or an app open (iOS has no "when unlocked" trigger, DEC-21).
- Storing anything on the relay's disk, or any drop that is not encrypted to the phone's key.
- Building the Shortcut itself (Ved builds it from the sheet).
- Garmin credentials or Garmin APIs (DEC-4).
- Sending synced data to any AI provider; the brief flow (E05) is unchanged.

## Success Metrics

- With the toggle off: no keys in IndexedDB and zero sync network calls (test).
- A test proves `BOXES` never holds plaintext; reading a drop deletes it.
- The cross-language round trip (Python `seal`, WebCrypto `openDrop`) passes.
- Live demo: finish a workout → open Messages → HuskyHealth shows the new workout.
