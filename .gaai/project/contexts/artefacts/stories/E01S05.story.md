# Story: Check the shell on Cloudflare Pages

## User Story

**As** Ved,
**I want** a quick check that the deployed shell has the CSP, shows its commit, installs on my iPhone and opens offline,
**so that** I know the base works before building features on it.

---

## Context

The static shell (E01S01–E01S04) is built and tested locally first. This story checks it once it is on Cloudflare Pages (DEC-19): the staging preview at `https://staging.huskyhealth.pages.dev` and production at `https://huskyhealth.vedsite.com`. Connecting the Pages project is Ved's step (SAFE-3); Delivery does not do it.

---

## Acceptance Criteria

- [ ] AC1: `scripts/check-pages.sh <base-url>` exits 0 only if `curl -sI <base-url>/` shows a `content-security-policy` header equal to the policy in `web/_headers`, and non-zero with a clear message otherwise; it also sends `curl -sI` to each path in the `SHELL` array parsed from `web/sw.js` and exits non-zero listing any path that did not return 200. Checked by running it against the staging preview URL and by running `scripts/check-pages.sh https://example.com`, which must exit non-zero.
- [ ] AC2: (compliance, PRIV-9) the same script checks that `connect-src` in the served CSP lists only `'self'` and the relay origin, and that `curl -sI <base-url>/sw.js` shows a `cache-control` header whose comma-separated directives include the token `no-cache`. Checked by running it.
- [ ] AC3: The script fetches `<base-url>/version.txt`, compares its first 7 characters with the first 7 characters of `git rev-parse origin/staging` (after a read-only `git fetch origin staging`), prints both, and exits non-zero on mismatch. Checked by running the script against the staging preview. manual (Ved): the About line on the installed app shows the same 7 characters.
- [ ] AC4: manual (Ved): on the iPhone, Safari → staging preview → Share → Add to Home Screen; the app opens full screen with the placeholder icon. Delivery writes these steps in the PR and does not claim them passed.
- [ ] AC5: manual (Ved): with the installed app opened once online, turn on airplane mode, close and reopen the app; it opens. Covers the shell only. Delivery writes these steps in the PR and does not claim them passed.

> All acceptance criteria must be verifiable. Vague criteria are invalid.

## Notes

- **STOP conditions (do not work around):**
  - If the Pages project or the staging preview isn't live, stop and report; don't connect it yourself.
  - If the served CSP differs from `web/_headers` (for example Cloudflare injected a script or header from Web Analytics, Rocket Loader, Email Obfuscation or Zaraz), stop and report to Ved; don't edit `_headers` to match.
  - AC5 needs every SHELL file on Pages (`cache.addAll` is all-or-nothing). If any SHELL path returns 404, list the missing paths and stop; don't trim SHELL or add stubs.
- The script uses only `curl`, `grep`, `git` (to read `origin/staging`) and POSIX shell. It sends nothing but GET/HEAD requests to the given URL.
