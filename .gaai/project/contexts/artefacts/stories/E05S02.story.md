# Story: Relay app with health check, token route and quiet errors

## User Story

**As an** athlete whose phone talks to the relay,
**I want** the relay to hand out short-lived single-use tokens and never write down what I send,
**so that** the relay holds nothing about me even if it is inspected.

---

## Context

`relay/app.py` is the Flask app gunicorn serves. This story creates it with the routes that need no AI: `GET /v1/healthz` (new: the gateway exposes `/v1/` only, so the old root `/healthz` moves under `/v1/`) and `POST /v1/token?kind=brief|listen`. It also sets the logging and error-handling rules every later route inherits (PRIV-6).

---

## Acceptance Criteria

- [ ] AC1: Given the Flask test client, when `GET /v1/healthz` is called, then it returns 200 with body `ok`; and every rule in `app.url_map` (except Flask's `static`, which is disabled) starts with `/v1/`. Checked by `pytest tests/relay/test_app_token.py`.
- [ ] AC2: Given `POST /v1/token?kind=brief` or `kind=listen`, then it returns 200 `{"token": "..."}` minted with a 600 s TTL; any other or missing `kind` returns a generic 422. Checked by pytest.
- [ ] AC3 [error-handling]: Given more than 30 token requests within one minute (global, in RAM, clock monkeypatched), then the 31st returns 429 with a generic body, and requests succeed again after the window. Checked by pytest.
- [ ] AC4 [error-handling]: Given any 4xx/5xx (bad JSON, unknown route, wrong method, an unhandled exception), then the response is a fixed generic JSON body that never echoes request input or `exc.errors()`. Checked by pytest that sends a sentinel string and asserts it is absent from every response body.
- [ ] AC5 [compliance]: Given requests whose bodies, query strings and headers carry a sentinel string, when they hit every route, then the sentinel never appears in captured logs at DEBUG level (`caplog`) or in stdout/stderr (`capfd`) — PRIV-6. Checked by `pytest tests/relay/test_no_logging.py`.
- [ ] AC6 [compliance]: The PRIV-6 grep `grep -rnE "log(ger)?\.\w+\(.*(body|request\.json|brief|prompt|audio|errors\(\))" relay/` returns nothing, and no `print(` appears in `relay/`.

## Notes

- Create the app with `Flask(__name__, static_folder=None)` so no non-`/v1/` route exists.
- Rate limiting is a small in-RAM sliding window; no extra dependency. It never records IPs (nginx strips them anyway).
- Do not enable Werkzeug or gunicorn access logs. Logging, if any, is counts only.
