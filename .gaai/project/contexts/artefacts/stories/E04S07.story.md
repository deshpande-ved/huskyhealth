# Story: End to end and airplane-mode run

## User Story

**As an** athlete,
**I want** to pick my Health export on my phone in airplane mode and see my training call,
**so that** I know, and can show, that my workouts never leave my phone.

---

## Context

**Addition beyond the runbook epic text.** The runbook's E04 text covers F2 and F5 only. Feature F6 "End to end + airplane-mode run" (1.5–2 h in the plan's feature menu, build-order step 6) had no epic, so Discovery (Session Brief D-8) adds it here rather than drop it silently (DEC-18). It is the headline demo: import → parser → features → engine → ASCII screen on the installed PWA, with zero network requests in airplane mode (PRIV-1, DEC-2).

The Delivery part is the wiring plus local automated checks. The phone run is Ved's.

---

## Acceptance Criteria

- [ ] AC1: Picking a file in the import input runs the parser worker and passes each worker message to `onImportMessage(state, msg)` from `view.js` (E04S10). On `done` it runs `saveFeatures()`, the engine and the main screen, in that order. A parser error goes through the same function, shows a plain message and keeps any stored features. manual (Ved): desktop browser with `tests/fixtures/synthetic-export.xml` (from E03): the four figures render; the Node check is AC2.
- [ ] AC2 (compliance, PRIV-1): a Node test runs the import-and-score path on `tests/fixtures/synthetic-export.xml` (parse → features → engine → screen model) with `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource` and `navigator.sendBeacon` replaced by stubs that throw and count calls; it ends with zero calls and four figures. Checked by `node --test tests/e2e-offline.test.js`.
- [ ] AC3 (compliance, PRIV-1): the PRIV-1 grep (`grep -nE "fetch\(|XMLHttpRequest|WebSocket|EventSource|sendBeacon|import\(['\"]https?:"`) over `web/js/parse-*.worker.js`, `features.js`, `engine.js`, `db.js`, `view.js`, `ascii.js` returns nothing.
- [ ] AC4: every file the app loads (each module reachable by `import` from `app.js` and each worker) is in `web/sw.js` SHELL. Checked by `node --test tests/shell.test.js`, which walks the imports and compares with SHELL.
- [ ] AC5: manual (Ved): on the installed PWA in airplane mode, import his real Health export, see the four figures, then tap **Forget everything** and see `NO DATA`; Safari Web Inspector's Network tab shows zero requests during import and scoring. Delivery writes the steps in the PR description and does not claim this passed.

> All acceptance criteria must be verifiable. Vague criteria are invalid.
