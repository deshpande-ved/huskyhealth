# Story: Shell page with About line

## User Story

**As an** athlete opening HuskyHealth,
**I want** a page that loads and shows which build I am running,
**so that** I can trust that the app on my phone matches the public code.

---

## Context

First file of the PWA (DEC-1). Cloudflare Pages writes the commit SHA to `web/version.txt` at build time (DEC-19); the About line shows it so anyone can match the running app to GitHub. The page carries no inline CSS or JS because the CSP (`style-src 'self'; script-src 'self'`) blocks it (FE-1).

---

## Acceptance Criteria

- [ ] AC1: `web/index.html` has `<meta name="viewport" content="width=device-width, initial-scale=1">`, `<meta name="theme-color" content="#191724">`, `<link rel="manifest" href="/manifest.webmanifest">`, `<link rel="apple-touch-icon" href="/icons/apple-touch-icon.png">`, `<link rel="stylesheet" href="/css/style.css">` and `<script type="module" src="/js/app.js">`. Checked by `node --test tests/web-shell.test.js`.
- [ ] AC2: (compliance, FE-1) no inline CSS or JS: `grep -rnE " on[a-z]+=|style=\"" web/ --include=*.html` returns nothing; `grep -rn "<script" web/ --include=*.html | grep -v "src="` returns nothing; `grep -rnE "innerHTML|outerHTML|insertAdjacentHTML|document\.write" web/` returns nothing.
- [ ] AC3: When `/version.txt` returns text that, after trimming, matches `^[0-9a-f]{7,40}$`, the About line shows `version <first 7 characters>`, set with `textContent`. The formatting is the exported function `formatVersion(text)` in `web/js/app.js`. Checked by `node --test tests/web-shell.test.js`, which imports `app.js` and calls `formatVersion`.
- [ ] AC4: When `/version.txt` is missing, empty, not a hex commit (for example an HTML body), or the fetch fails (offline, local dev), the About line shows `version unknown` and no error is thrown. Checked by `node --test tests/web-shell.test.js` on `formatVersion`, including a case with an HTML body.
- [ ] AC5: (compliance, PRIV-9) `web/js/app.js` fetches only the same-origin path `/version.txt`; no other URL and no third-party script, font or stylesheet is referenced. Checked by `grep -rnE "https?://" web/index.html web/js/app.js web/css/style.css` returning nothing.
- [ ] AC6: `web/css/style.css` uses system monospace only (`ui-monospace, "SF Mono", Menlo, monospace`), no `@font-face`, no font URLs (FE-3). Checked by grep.

> All acceptance criteria must be verifiable. Vague criteria are invalid.

- Service worker registration (E01S03), manifest and icons (E01S02), `_headers` (E01S04).
- Creating or committing `web/version.txt` (the Pages build writes it).

## Notes

- `app.js` is the shell's entry module; later epics extend it. `formatVersion` is exported and importable in Node: all DOM and service-worker code runs only inside `if (typeof document !== "undefined")`, so `node --test` can import the module.
- `version.txt` is not in the 10.4 SHELL list, so offline the About line falls back to `version unknown`. Do not add it to SHELL.
- Do not create `web/js/ascii.js` here, even though build-order step 2 mentions an empty one: the epic text scopes it out (E04 owns it).
