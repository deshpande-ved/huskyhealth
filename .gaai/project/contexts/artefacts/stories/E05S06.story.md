# Story: Relay on the Pi behind Funnel :10000

## User Story

**As** an athlete using the installed app from anywhere,
**I want** the relay reachable at its public HTTPS address,
**so that** I can get a brief from my phone, with TLS ending on Ved's own hardware.

---

## Context

The relay runs on the Pi and is published with Tailscale Funnel on port 10000 (DEC-9), at `https://veds-pi5.polecat-nominal.ts.net:10000`. Every Pi command needs Ved's hands (SAFE-3). Delivery writes the deploy steps as a short doc and makes sure the existing check scripts run against the public URL; Ved runs them.

---

## Acceptance Criteria

- [ ] AC1: `docs/relay-deploy.md` lists, as paste-ready commands from the memory source: clone (owner as a `<owner>` placeholder), create `.env` with empty keys and `chmod 600`, `docker compose up -d --build`, `sudo tailscale funnel --bg --https=10000 http://localhost:8090`, `tailscale funnel status`, and the redeploy line. Checked by a `grep -n` for each required command (clone, `chmod 600`, `docker compose up -d --build`, `sudo tailscale funnel --bg --https=10000 http://localhost:8090`, `tailscale funnel status`, the redeploy line), each matching at least once; `grep -n "serve reset" docs/relay-deploy.md` returns only the "never run" warning.
- [ ] AC2 [compliance]: SAFE-2: `docs/relay-deploy.md` has no host name other than the public relay URL, no LAN IP, no SSH alias, no port outside 8090, 8091, 8000, 8080, 8082, 8083, 10000, and no GitHub username. Checked by grep for IPv4 patterns and `ssh ` returning nothing.
- [ ] AC3: manual (Ved): on the Pi, after `docker compose up -d --build`, `curl -s http://127.0.0.1:8090/v1/healthz` prints `ok` and `scripts/check-relay-container.sh` passes.
- [ ] AC4 [compliance]: manual (Ved): `tailscale funnel status` shows `10000 → 8090` and every Funnel entry that existed before is still there. Never run `tailscale serve reset` (SAFE-4).
- [ ] AC5 [error-handling]: manual (Ved): from the Mac, `scripts/check-gateway.sh https://veds-pi5.polecat-nominal.ts.net:10000` passes (healthz, 404 outside `/v1/`, exact CORS). If it fails, remove only the relay's own Funnel entry on 10000 and report; touch nothing else.
- [ ] AC6 [compliance]: manual (Ved): the Pi's `.env` is mode 600, filled by hand, and its contents never appear on screen, in a terminal recording or in a commit (SAFE-5).
