# Story: Presidio PII scanner module with a device-name recognizer

## User Story

**As an** athlete asking for a brief,
**I want** an independent PII tripwire to check every string the relay handles,
**so that** a name, device name or contact detail can't slip out even if the schema misses it.

---

## Context

DEC-10 makes Presidio the relay's PII tripwire (PRIV-8). This story replaces the E05S03 no-op stub in `relay/pii.py` with the real scanner, exactly as sketched in the evidence memory (plan 9.1): spaCy small model, a custom `DEVICE_NAME` recognizer for `<owner>'s Apple Watch / iPhone / iPad`, `DATE_TIME` excluded so "7-day" doesn't trip it, and `strings_of()` that collects keys and string values but never numbers. The function names and signatures stay the same, so E05S03's route and tests keep working. Wiring into the brief route is E08S02.

E08 adds the Presidio packages itself: `presidio-analyzer` goes into `relay/requirements.txt` and the spaCy model download goes into `relay/Dockerfile`. E05 does not add them.

## Acceptance Criteria

- [ ] AC1: `relay/pii.py` exposes `strings_of(obj)` and `pii_types(text) -> list[str]` per the memory sketch, replacing the E05S03 stub; `ENTITIES` contains `DEVICE_NAME` and does not contain `DATE_TIME`. Check: `pytest tests/relay/test_pii.py`; `grep -n DATE_TIME relay/pii.py | grep -v '#'` returns nothing.
- [ ] AC2: `pii_types("synced from Alex's Apple Watch")` and the curly-apostrophe form (`Alex’s iPhone`) both return `["DEVICE_NAME"]`; `pii_types("7-day load is up")` returns `[]`. Rule (Ved): `pii_types` drops a PERSON hit that lies fully inside a DEVICE_NAME span, so the made-up name inside a device name is not reported as PERSON; the request is still blocked because DEVICE_NAME is reported. A PERSON hit outside any DEVICE_NAME span is still reported. Unit test cases: `pii_types("Alex's Apple Watch")` returns `["DEVICE_NAME"]`; a text with a PERSON outside any DEVICE_NAME span still returns `"PERSON"`. Check: `pytest tests/relay/test_pii.py`.
- [ ] AC3: `strings_of` returns dict keys and string values, recursing into lists and dicts, and never returns numbers or number arrays (e.g. `{"zone_pct7": [10, 20, 30, 25, 15]}` → `["zone_pct7"]`). Check: `pytest tests/relay/test_pii.py`.
- [ ] AC4: 0 findings on fixture briefs: `pii_types` on the joined `strings_of` of `tests/fixtures/brief_synthetic.json`, and on its bucketed prompt string (`json.dumps(bucketize(BriefIn.model_validate(...)), separators=(",", ":"))`), returns `[]`. Check: `pytest tests/relay/test_pii.py`. STOP condition: if the prompt string trips an entity (e.g. `PHONE_NUMBER` on digit runs), stop and report; do not raise the threshold, drop entities or skip the prompt scan to make it pass.
- [ ] AC5 (compliance): synthetic data only. Fixtures use a made-up name (no real person, no real export data, SAFE-1); `relay/pii.py` never logs or prints analyzed text or matched spans (PRIV-6). Check: `grep -nE "print\(|log(ger)?\." relay/pii.py` returns nothing.
- [ ] AC6: the analyzer loads with no network at runtime. E08S01 adds the line `presidio-analyzer` to `relay/requirements.txt` and the line `RUN python -m spacy download en_core_web_sm` to `relay/Dockerfile`, after the pip install (E05S04 writes that Dockerfile without it). Check: `grep -n "presidio-analyzer" relay/requirements.txt` and `grep -n "en_core_web_sm" relay/Dockerfile` both match; `pytest tests/relay` passes with the model installed locally and the socket guard in `tests/relay/conftest.py` on (autouse fixture: `socket.socket.connect` raises). STOP condition: if the model cannot load offline, stop and report.

## Notes

- Build on `python:3.12-slim`; don't assume Microsoft's Presidio image runs on ARM.
- `tests/fixtures/brief_synthetic.json` is a separate file from E05's `tests/fixtures/briefin-sample.json`. It may copy that file's values, but keep it as its own fixture so E08's binding names stay stable.
- `tldextract` gotcha: in the jailed relay it falls back to its bundled suffix list. `HOME=/tmp` (tmpfs, set in E05's compose) gives it somewhere to write. If the analyzer tries a network fetch inside the container, stop and report.
- Pattern from memory: `r"\b[\w\-]+['’]s\s+(?:Apple\s+Watch|iPhone|iPad)\b"`, score 0.9; analyzer `score_threshold=0.5`.
