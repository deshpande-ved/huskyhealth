# Story: Vendor Garmin's FIT SDK for offline use (H-1 check)

## User Story

**As a** Garmin owner using HuskyHealth,
**I want** the app to carry Garmin's own FIT decoder inside it,
**so that** my `.fit` files can be read on my phone with no network and no third-party server.

---

## Context

Plan 6.2/6.4 decodes `.fit` files in the browser with Garmin's official JavaScript SDK (`@garmin/fitsdk`). H-1 is unverified: that the SDK runs as plain ES modules in a browser with no network, and that its licence (`LICENSE.txt`, Garmin's FIT licence, not an OSI licence) lets us redistribute it in a public repo. This story checks both before any parser work. A CDN copy is not allowed (PRIV-1, CSP `connect-src`/`script-src 'self'`).

At planning time the npm package was `21.221.0`, `type: module`, entry `src/index.js`. Use the latest stable version and record it.

---

## Acceptance Criteria

- [ ] AC1 (compliance, H-1 STOP): The SDK's `LICENSE.txt` is read and allows redistributing the SDK source inside a public repo and a web app. If it does not, or it is unclear, **STOP and report the exact clause to Ved; do not vendor it and do not work around it** (no CDN, no rewrite). Checked by: the licence clause quoted in the PR description.
- [ ] AC2: The package's `src/` is copied unmodified to `web/vendor/fitsdk/`, with its `LICENSE.txt` and a one-line `VERSION` file (package name + version). No build step and no bundler. Checked by: `diff -r -x VERSION -x LICENSE.txt package/src web/vendor/fitsdk` (`package/` is the unpacked npm tarball) shows no differences (command shown in the PR).
- [ ] AC3 (compliance, PRIV-1): The vendored SDK makes no network calls and imports nothing remote or Node-only. Checked by: `grep -rnE "fetch\(|XMLHttpRequest|WebSocket|EventSource|sendBeacon|import\(['\"]https?:|from ['\"]https?:" web/vendor/fitsdk/` returns nothing, and `grep -rnE "from ['\"][^./]|require\(|process\.|Buffer" web/vendor/fitsdk/` returns nothing. If either grep finds a hit, **STOP and report**.
- [ ] AC4: `tests/fitsdk-vendor.test.js` (`node --test`) imports `Decoder` and `Stream` from `web/vendor/fitsdk/index.js` and decodes a small FIT byte array built in memory (with the SDK's `Encoder` if it ships one; otherwise from hand-written bytes in the test). If the SDK cannot be imported as ES modules from that path, **STOP and report** (H-1 false).
- [ ] AC5 (error-handling): The same test shows that random non-FIT bytes give `isFIT() === false` without throwing.
- [ ] AC6 (compliance, SAFE-1): No `.fit` file is added. Checked by: `git ls-files '*.fit'` prints nothing.

> All acceptance criteria must be verifiable. Vague criteria are invalid.
