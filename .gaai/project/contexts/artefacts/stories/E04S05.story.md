# Story: Plain view toggle

## User Story

**As a** user who uses a screen reader, a large text size, or just prefers words,
**I want** to swap every ASCII figure for plain text,
**so that** I get the same numbers without reading character art.

---

## Context

FE-4 requires a Plain view toggle that swaps every figure for plain text, and says screen readers never read raw ASCII. The figures from E04S04 already carry their numbers in an `aria-label`; Plain view shows those numbers as ordinary text instead of the `<pre>` art.

---

## Acceptance Criteria

- [ ] AC1: `web/index.html` has one Plain view `<button>` with `aria-pressed`, labeled "Plain view". Checked by `node --test tests/plain.test.js` (reads `index.html`).
- [ ] AC2: For every figure in the screen model, the plain text holds the same numbers as its `aria-label` and no ramp or box characters. Checked by `node --test tests/plain.test.js` using the E04S04 fixture.
- [ ] AC3: Pressing the button hides every figure `<pre>` and shows its plain text, flips `aria-pressed`, and pressing again restores the figures; the References links still work in both views. manual (Ved): desktop browser, then the installed PWA with VoiceOver on.
- [ ] AC4 (compliance, FE-1 / FE-4): the toggle is wired from `app.js` with `addEventListener` (no `on*=` attribute) and shows/hides by class, not inline `style=""`; FE-1 greps from `frontend.rules.md` return nothing over `web/`.

> All acceptance criteria must be verifiable. Vague criteria are invalid.
