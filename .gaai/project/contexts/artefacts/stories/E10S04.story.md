# Story: Synthetic brief cohort and risk check script

## User Story

**As** Ved, presenting the privacy story,
**I want** a synthetic cohort of brief requests before and after rounding, plus a quick risk check,
**so that** I can measure, not just claim, how de-identified the brief is.

---

## Context

Feature F18 "ARX risk analysis" (2–3 h), part 1. **Cut together with E10S05**; the two ship or are cut as one unit, independent of F16, F17 and F19 (DEC-18). Lower priority: everything that leaves is already rounded aggregates.

ARX measures re-identification risk under prosecutor, journalist and marketer attacker models (NIST IR 8053). Plan steps: 1) generate a synthetic cohort of `BriefIn` rows; 2) mark every column quasi-identifying, k = 5; 3) read the risk view before and after rounding; 4) copy chosen widths into `bucketize()`. This story does step 1 and writes the steps for 2–3; E10S05 does 3–4.

`risk.py` is our own quick cross-check (smallest equivalence class, prosecutor risk = 1 / class size), labelled as ours. It does not replace ARX.

- The cohort is synthetic only (SAFE-1); no real export is read.
- `bucketize()` must be the relay's own code path. If importing it needs an API key or a network client, move `r()` and `bucketize()` into `relay/rounding.py` and re-export them from `relay/ai.py` with no behaviour change (E05's tests must still pass).

---

## Acceptance Criteria

- [ ] AC1: `make_cohort.py --n 4000 --seed 1 --out DIR` writes `raw.csv` and `rounded.csv`, one row per synthetic `BriefIn` (lists flattened to columns), each raw row valid against `BriefIn` and each rounded row produced by the relay's `bucketize()`; the same seed gives byte-identical files. Checked by pytest.
- [ ] AC2 (compliance): `make_cohort.py` requires `--out` (no default). It reads no input files and makes no network calls. Checked by pytest: it writes to `tmp_path` with `builtins.open` patched to raise on read modes and `socket.socket` patched to raise.
- [ ] AC3: `risk.py FILE` prints, treating every column as quasi-identifying: row count, smallest equivalence class (k), share of rows in classes smaller than 5, and highest prosecutor risk (1 / k). Checked by pytest on a hand-made 10-row table with known answers.
- [ ] AC4 (error-handling): `risk.py` on a missing file, an empty file or a file whose columns don't match `BriefIn` exits non-zero with a one-line message and no traceback. Checked by pytest.
- [ ] AC5 (compliance): `docs/arx-steps.md` gives Ved the ARX steps: import both CSVs, mark every column quasi-identifying, k = 5, read the risk view for prosecutor, journalist and marketer models, and where to record the numbers; it says "de-identified", never "anonymous", and names no homelab details. Checked by grep (three model names present; CLAIM-2 grep clean; runbook D5 scrub grep prints `clean`).
