# Story: Paste-ready proof scripts: replay, smuggle, pi-proof

## User Story

**As** Ved presenting to judges,
**I want** three short scripts that prove token replay fails, a smuggled device name is rejected, and the relay kept nothing,
**so that** the privacy claims are shown live, not just stated.

---

## Context

Three paste-ready scripts prove the relay's claims. `replay.sh` and `smuggle.sh` run on the Mac against the relay; `pi-proof.sh` runs on the Pi with the token printed by `replay.sh`. Delivery writes and locally checks the scripts; running them live is Ved's job (T-1, O-3, SAFE-3: any command on the Pi is Ved's). The scripts go into a public repo, so their behaviour is fully restated in AC1.

---

## Acceptance Criteria

- [ ] AC1: `scripts/replay.sh`, `scripts/smuggle.sh` and `scripts/pi-proof.sh` exist, are executable, start with `#!/usr/bin/env bash` and `set -eu`. replay posts `tests/fixtures/brief_synthetic.json` twice with one brief token (from `POST /v1/token?kind=brief`) and prints both status codes then the token; smuggle posts `tests/fixtures/brief_smuggle.json` and prints the body piped through `python3 -m json.tool`; pi-proof prints `readonly=… mounts=…`, the `docker diff` line count, and the token hit count. Check: `bash -n` on each, `test -x` on each, and `shellcheck` if installed.
- [ ] AC2 (compliance): the only host in the scripts is the relay origin `https://veds-pi5.polecat-nominal.ts.net:10000` (D-9), set as the default in `H="${RELAY:-https://veds-pi5.polecat-nominal.ts.net:10000}"` so Delivery can point the scripts at `http://127.0.0.1:8090`; the grep below still sees only the relay origin. No LAN IPs, SSH aliases, other hostnames, ports other than 10000, keys or tokens (SAFE-2). Check: `grep -noE "https?://[^ \"/}]+" scripts/*.sh | sort -u` shows only the relay origin, and `grep -nE "[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+|\bssh\b" scripts/*.sh` returns nothing.
- [ ] AC3: `pi-proof.sh` with no argument exits non-zero with a one-line usage message instead of grepping for an empty string. Check: `bash scripts/pi-proof.sh; echo $?` on the Mac prints the usage line and a non-zero code before any `docker` call.
- [ ] AC4: manual (Ved): `scripts/replay.sh` against the live relay prints `200` then `410`.
- [ ] AC5: manual (Ved): `scripts/smuggle.sh` against the live relay prints a 422 body. The check runs on the `python3 -m json.tool` output and compares parsed values: `schema_ok` is `false` and `pii` equals `["DEVICE_NAME"]`, so JSON spacing does not matter.
- [ ] AC6: manual (Ved): on the Pi, `scripts/pi-proof.sh <token from replay.sh>` prints `readonly=true mounts=0`, `files changed in relay container: 0` and `token hits in logs: 0`.
