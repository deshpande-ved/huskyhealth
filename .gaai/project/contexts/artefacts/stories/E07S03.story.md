# Story: Coach's voice from a consenting coach

## User Story

**As an** athlete on a team,
**I want** my brief read in my own coach's voice, clearly labelled as an AI voice,
**so that** it feels like my coach, and the coach stays in control of their voice.

---

## Context

Cloning happens once, by hand, in Gradium Studio: a consenting coach records about 10 s (demo: Ved, as the club squash VP). The resulting voice ID goes into the Pi's `.env` as `GRADIUM_VOICE_ID`; the relay uses it for `/v1/speak`. The voice is only ever a consenting coach's, never a user's (DEC-17, PRIV-5). The coach can delete the clone in Studio at any time.

Claude Code can't use Gradium Studio, so Delivery writes the steps and wires the env var; Ved does the clone.

---

## Acceptance Criteria

- [ ] AC1: `docs/coach-voice.md` lists the Studio steps for Ved: get the coach's written consent first (kept offline, never committed), record ~10 s, create the instant clone, copy the voice ID into the Pi's `.env` as `GRADIUM_VOICE_ID` (never into the repo), and how the coach deletes the clone. It has no keys, voice IDs, emails or homelab details. Check: reviewer reads it; the runbook's D5 scrub grep prints `clean`.
- [ ] AC2: when `GRADIUM_VOICE_ID` is set, the relay sends it as the voice field Gradium's reference names; when it is unset, empty or `REPLACE_ME`, it uses the default voice from E07S01. Check: pytest with Gradium mocked, for set, unset, empty and `REPLACE_ME`.
- [ ] AC3 (compliance): the relay sets `X-Voice: coach` or `X-Voice: default` on the `/v1/speak` response; whenever the cloned voice plays, the PWA shows "AI voice of Coach <name>" next to the player; the coach name comes from one config value in `web/`. Any new file under `web/` (for example `web/js/config.js`) is in `SHELL` in `web/sw.js`, and `CACHE` is bumped (R-1). Check: `node --test` asserts the label renders only when `X-Voice` is `coach`; `node --test tests/web-sw.test.js` covers the SHELL entry.
- [ ] AC4 (error-handling): if Gradium rejects the voice ID (for example the coach deleted the clone), `/v1/speak` returns 502 with a generic message, logs nothing about the ID or text, and the PWA offers the phone voice (E07S02). Check: pytest with a mocked Gradium error.
- [ ] AC5: manual (Ved): after the clone, the brief plays in the cloned voice on the iPhone, with the label showing.

> All acceptance criteria must be verifiable. Vague criteria are invalid.
