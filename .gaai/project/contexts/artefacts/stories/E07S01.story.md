# Story: Relay speaks the brief through Gradium

## User Story

**As an** athlete who asked to hear my brief,
**I want** the relay to turn exactly that brief into speech,
**so that** I can listen to it, and Gradium gets one passage of coaching text and nothing else.

---

## Context

`POST /v1/speak` takes `SpeakIn` (`{text}`) with a `Bearer` speak token minted by `/v1/brief` and bound to `digest(text)` (E05). Steps: validate `SpeakIn` → `burn(token, "speak", bound=digest(text))` → check the hourly limit → call Gradium at `GRADIUM_BASE_URL` (`http://egress:8082`, mitmweb in front of Gradium) → return audio with `Cache-Control: no-store`.

Gradium's API details are NOT in project memory. The exact path, auth header, request body, response format, and whether word timings come back must be read from Gradium's official API reference (https://docs.gradium.ai/api-reference/introduction). If one-shot REST speech isn't offered, use the WebSocket endpoint the reference documents and add `websockets` to `relay/requirements.txt`.

The hourly limiter built here is reused by `/v1/listen` (E07S04).

---

## Acceptance Criteria

- [ ] AC1: Before writing the client, Delivery reads Gradium's official API reference and records at the top of `relay/gradium.py`: the doc URL(s) used, the speech path, the auth header name, every request body field sent, the response format it chose (raw audio, or JSON `{audio_b64, words:[{w,start,end}]}`), and whether word-level timings are returned. Nothing is guessed. If the reference shows no word timings, stop and report before E07S02 starts (H-3); don't work around it. Check: `grep -n "docs.gradium.ai" relay/gradium.py`, and the reviewer compares the fields against the reference.
- [ ] AC2: With a valid speak token and the exact brief text, `/v1/speak` returns the audio in the format AC1 recorded (raw audio, or JSON `{audio_b64, words:[{w,start,end}]}`) with `Cache-Control: no-store`. Check: pytest with Gradium mocked asserts the response matches the recorded format.
- [ ] AC3 (error-handling): text changed by one character → 410; a reused token → 410; an unknown field or wrong type in the body → 422 that does not echo the input; Gradium unreachable or erroring → 502 with a generic message and the token stays burned. Check: pytest.
- [ ] AC4: an hourly limit on `/v1/speak` (`SPEAK_LIMIT_PER_HOUR`, default 30): the request over the limit → 429 and Gradium is not called. Check: pytest with a fake clock.
- [ ] AC5 (compliance): Gradium is called only through `GRADIUM_BASE_URL`, with the key from `GRADIUM_API_KEY` sent only in the auth header; the body carries the one passage plus only the voice/format fields the reference requires. Neither the text, the audio nor the key is logged on any path, success or failure. Check: pytest captures all log output (caplog and capsys) on success, 410, 422, 429 and 502 paths and asserts the text, audio bytes and key never appear; the PRIV-6 grep (`grep -rnE "log(ger)?\.\w+\(.*(body|request\.json|brief|prompt|audio|errors\(\))" relay/`) returns nothing.
- [ ] AC6: manual (Ved): with the compose stack up, one tap on "Read it aloud" shows one Gradium request in mitmweb whose Request body tab holds one passage (or, if the reference forces WebSocket, its WebSocket messages tab). Never show headers (SAFE-5).

> All acceptance criteria must be verifiable. Vague criteria are invalid.

## Out of Scope

- The PWA side (consent, playback, captions): E07S02.

- `/v1/token`, `/v1/brief`, `tokens.py`, `SpeakIn` (E05).
- Presidio on the text: the text is the brief that E08S02 scans before `/v1/brief` returns it (PRIV-8), and the speak token's hash binding guarantees the text sent to Gradium is that exact scanned text. If E08 is cut, the brief text is still only Claude's reply to numbers-only input.

## Notes

- Region: the egress forwards `:8082` to `us.api.gradium.ai` (or `eu.`); the relay never calls Gradium directly (the internal network has no other route out).
- Gunicorn runs one worker, so the RAM limiter is consistent (PRIV-7).
- Error responses must never include Gradium's error body if it could echo the text.
